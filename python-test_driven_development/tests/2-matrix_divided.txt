This module defines the function matrix_divided(matrix, div) that divides
all the elements of a matrix and returns a new matrix.

Import the function:
>>> matrix_divided = __import__('2-matrix_divided').matrix_divided

The module and the function are documented:
>>> len(__import__('2-matrix_divided').__doc__) > 10
True
>>> len(matrix_divided.__doc__) > 10
True

The example of the project, and the original matrix is not changed:
>>> matrix = [[1, 2, 3], [4, 5, 6]]
>>> matrix_divided(matrix, 3)
[[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]
>>> matrix
[[1, 2, 3], [4, 5, 6]]

The result is a new matrix with new rows:
>>> result = matrix_divided(matrix, 1)
>>> result is matrix
False
>>> result[0] is matrix[0]
False
