Test cases for 0-add_integer.py
===============================

This module defines the function add_integer(a, b=98) that adds two
integers or floats and returns an integer.

Import the function:
>>> add_integer = __import__('0-add_integer').add_integer

The module and the function are documented:
>>> len(__import__('0-add_integer').__doc__) > 10
True
>>> len(add_integer.__doc__) > 10
True

Two integers:
>>> add_integer(1, 2)
3
>>> add_integer(100, -2)
98
>>> add_integer(-5, -7)
-12
>>> add_integer(0, 0)
0

The second argument is 98 by default:
>>> add_integer(2)
100
>>> add_integer(0)
98
>>> add_integer(-98)
0

Floats are casted to integers (cut toward zero) before the addition:
>>> add_integer(100.3, -2)
98
>>> add_integer(1.9, 2.9)
3
>>> add_integer(-1.9, 1)
0
>>> add_integer(2.5, 3.5)
5
>>> add_integer(1.0, 1.0)
2
>>> add_integer(2.7)
100

The result is always an integer:
>>> type(add_integer(1.5, 2.5))
<class 'int'>
>>> type(add_integer(3, 4))
<class 'int'>

Big numbers:
>>> add_integer(10 ** 20, 1)
100000000000000000001
>>> add_integer(-10 ** 20, 10 ** 20)
0
