# Python - Network #1

This project covers fetching internet resources in Python 3 with the
`urllib` package and the `requests` package: GET and POST requests,
response headers, HTTP errors, JSON and Basic Authentication.

| File | Description |
|------|-------------|
| 0-hbtn_status.py | Fetches a status page with urllib |
| 1-hbtn_header.py | Displays the X-Request-Id header with urllib |
| 2-post_email.py | Sends a POST request with an email using urllib |
| 3-error_code.py | Handles urllib HTTP errors |
| 4-hbtn_status.py | Fetches a status page with requests |
| 5-hbtn_header.py | Displays the X-Request-Id header with requests |
| 6-post_email.py | Sends a POST request with an email using requests |
| 7-error_code.py | Prints the error code of a failing response |
| 8-json_api.py | Searches a user with a POST request and reads JSON |
| 10-my_github.py | Displays the id of a GitHub user with Basic Authentication |

## Requirements
- Ubuntu 14.04 LTS, python3 (3.4.3)
- PEP 8 style
