# Python - Everything is object

This project explores how Python handles objects: identity, types,
mutable and immutable objects, aliases, and how arguments are passed
to functions.

Most tasks are one-line answer files (`N-answer.txt`). Task 19 is a
small script, and task 29 is a blog post.

| File | Description |
|------|-------------|
| 0 to 18-answer.txt | Questions about type, id, identity and mutability |
| 19-copy_list.py | Function that returns a copy of a list |
| 20 to 28-answer.txt | Questions about tuples and list identity |

## Requirements
- Ubuntu 20.04 LTS, python3 (3.8.5)
- pycodestyle 2.7.*
