# Python - More Classes and Objects

This project goes deeper into object-oriented programming in Python 3:
class attributes, static methods, class methods, `__str__`, `__repr__`
and `__del__`.

Each file builds on the previous one to create a `Rectangle` class.

| File | Description |
|------|-------------|
| 0-rectangle.py | An empty Rectangle class |
| 1-rectangle.py | Private width and height with validation |
| 2-rectangle.py | Area and perimeter |
| 3-rectangle.py | String representation with # |
| 4-rectangle.py | repr that works with eval() |
| 5-rectangle.py | Message on instance deletion |
| 6-rectangle.py | Count of instances |
| 7-rectangle.py | Customizable print symbol |
| 8-rectangle.py | Compare rectangles (static method) |
| 9-rectangle.py | Square constructor (class method) |

## Requirements
- Ubuntu 20.04 LTS, python3 (3.8.5)
- pycodestyle 2.7.*
