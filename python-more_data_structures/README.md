# Python - More Data Structures

This project contains Python functions for working with lists, sets,
dictionaries, and Roman numerals.

## Tasks

- 0: Squared simple
- 1: Search and replace
- 2: Unique addition
- 3: Present in both
- 4: Only differents
- 5: Number of keys
- 6: Print sorted dictionary
- 7: Update dictionary
- 8: Simple delete by key
- 9: Multiply by 2
- 10: Best score
- 11: Multiply by using map
- 12: Roman to Integer

## Requirements

Python 3.8.5 or compatible Python 3.
