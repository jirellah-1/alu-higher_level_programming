# Python - Hello, World

This project introduces the basics of Python programming and shell scripting.

## Tasks

- 0-run: Run a Python script using the PYFILE environment variable.
- 1-run_inline: Execute Python code stored in PYCODE.
- 2-print.py: Print a text message.
- 3-print_number.py: Print an integer using an f-string.
- 4-print_float.py: Print a floating-point number to two decimal places.
- 5-print_string.py: Repeat and slice a string.
- 6-concat.py: Concatenate strings.
- 7-edges.py: Practice string slicing.
- 8-concat_edges.py: Create a sentence using string concatenation.
- 9-easter_egg.py: Display the Zen of Python.
