# Python - Input/Output

This project covers reading and writing files in Python 3, the `with`
statement, and JSON serialization and deserialization of objects.

| File | Description |
|------|-------------|
| 0-read_file.py | Reads a text file and prints it |
| 1-write_file.py | Writes a string to a text file |
| 2-append_write.py | Appends a string to a text file |
| 3-to_json_string.py | Returns the JSON representation of an object |
| 4-from_json_string.py | Returns an object represented by a JSON string |
| 5-save_to_json_file.py | Writes an object to a file as JSON |
| 6-load_from_json_file.py | Creates an object from a JSON file |
| 7-add_item.py | Adds arguments to a list saved in add_item.json |
| 8-class_to_json.py | Dictionary description of an object |
| 9-student.py | Student class with `to_json` |
| 10-student.py | Student class with a filtered `to_json` |
| 11-student.py | Student class that can reload its attributes |
| 12-pascal_triangle.py | Pascal's triangle |

## Requirements
- Ubuntu 20.04 LTS, python3 (3.8.5)
- pycodestyle 2.7.*
